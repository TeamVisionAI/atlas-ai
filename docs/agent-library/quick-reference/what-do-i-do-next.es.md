# ¿Qué hago ahora?

Lista diaria breve para usuarios de campo.

## Inicio del día

- [ ] Revisa **Team Dashboard** o **Mission Control** para prioridades.
- [ ] Revisa las citas de hoy.
- [ ] Haz seguimiento a prospectos abiertos.

## Durante el día

- [ ] Registra nuevos contactos en **Quick Capture**.
- [ ] Confirma entrevistas y actualiza resultados.
- [ ] Usa guiones aprobados de **Scripts y manejo de objeciones**.

## Fin del día

- [ ] Limpia los seguimientos programados para mañana.
- [ ] Anota prospectos que necesiten apoyo del upline.

## ¿Necesitas ayuda?

- Busca en este Centro de Conocimiento guiones y procedimientos.
- Pregunta a tu upline sobre políticas específicas de la organización.
