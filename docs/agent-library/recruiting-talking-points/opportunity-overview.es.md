# Resumen de la oportunidad

Esquema breve de puntos de conversación para las primeras charlas.

## Qué cubrir

1. **Propósito** — Los invitas a conocer una oportunidad de negocio (no un empleo garantizado).
2. **Flexibilidad** — Algunas personas exploran a tiempo parcial; otras pasan a tiempo completo después del licenciamiento.
3. **Siguiente paso** — Una conversación o entrevista breve para ver si encaja.

## Apertura de ejemplo

> Quería compartirte una oportunidad para construir tu propio negocio con capacitación y apoyo. ¿Estarías abierto a una conversación corta esta semana?

## Mantén la conversación natural

- Una idea a la vez.
- Haz pausas para preguntas.
- No sobrecargues con detalles de licenciamiento o producto en el primer mensaje.
