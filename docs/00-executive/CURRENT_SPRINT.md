# Sprint 17 — Atlas Self-Awareness

## Objective

Replace stale, hardcoded Knowledge Hub dashboard values with live platform status derived from authoritative repository sources.

## Scope

- Platform status service (`GET /api/platform-status`)
- Authoritative sprint document (`CURRENT_SPRINT.md`)
- Git metadata and documentation freshness
- External Meta review status (manual backend source)
- Knowledge Hub dashboard wired to live API data

## Out of scope

- Redesigning Knowledge Hub layout or navigation
- Automatic Meta review polling (no approved API)
